《雷隙 THUNDERGAP》产品需求文档

一款把「雷雨」做成核心机制的第三人称氛围动作游戏。玩家扮演能听见闪电回声的少女林隙， 在被雷暴穹顶压住的漆黑城市里，用声呐式的回声脉冲探路、拾回碎成八片的求救信号， 赶在穹顶闭合前抵达广播塔。本文档定义产品的目标、范围、功能优先级、数值基线与技术路径。

01产品定义

一句话定义：在雷暴吞没城市之前，用一次回声脉冲，照亮一整座漆黑的城市。

产品类型
第三人称 3D 动作 / 氛围探索 / 短局重玩
核心平台
桌面浏览器（WebGL，即点即玩）；后续扩展 PC / 主机
单局时长
4–7 分钟（雷暴穹顶倒计时 300 秒）
操作方式
键鼠（WASD + 空格 + E）
叙事载体
环境叙事 + 八段无线电残句字幕
产品定位
「天气叙事」三部曲第一部 · 主题为「雷」（后续为「雾」「雪」）

产品三原则

  • 天气即玩法，而非滤镜。雷雨同时承担敌人、路标、计时器与叙事者四重角色。
  • 黑暗不是惩罚。回声脉冲把「看不见」转化为一次主动的、有节奏感的敲击——安静等待本身就是策略。
  • 三分钟能讲完的故事。单局足够短，失败成本低，靠反复重玩拼出完整叙事。

02背景与机会

市场观察

市场上天气大多作为视觉氛围存在（雨、雪、雾），极少被设计成可交互的核心机制。 与此同时，「黑暗 + 声音导航」这一方向已被验证具备强记忆点（如听觉驱动的探索游戏）， 但多停留在 2D 或步行模拟器形态，缺少动作化的紧张感与清晰的单局目标。

机会点

  • 机制空白：把「声音探路」从 2D 听觉实验推进到 3D 动作场景，形成差异化手感。
  • 传播性：「一发脉冲点亮整座雨夜城市」是天然的短视频高光时刻，获客成本低。
  • 零门槛：网页即点即玩，无下载、无账号，适合碎片时间传播与媒体试玩。
  • 可延展：「天气叙事」框架可沉淀为系列 IP（雷 / 雾 / 雪），复用技术与美术资产管线。

参考与差异

参考对象借鉴点我们的差异
听觉驱动探索游戏以声音替代视觉作为主要信息通道加入动作压力（落雷、倒计时），把「听」变成「边跑边听」
超自然惊悚步行模拟氛围优先、弱化战斗明确单局目标与数值反馈，避免节奏松散
开放世界步行/送货类行走本身构成体验压缩到 3–6 分钟单局，提高重玩密度
光照即玩法类作品光作为资源与武器光不是武器而是「回声」，且由玩家主动消耗共鸣值换取

05核心玩法循环

核心循环（秒级）
漆黑→ 释放脉冲探路→ 读取轮廓与碎片→ 决策路线→ 移动 / 躲避落雷↺
单局循环（分钟级）
收集 8 片雷纹→ 穹顶压力递增→ 冲刺广播塔→ 结局（送出 / 遗失）→ 重来一夜
元循环（跨局）
解锁叙事残句→ 拼出完整真相→ 挑战更高难度 / 新城区

节奏曲线设计

穹顶进度设计意图主要压力源
0 – 25%教学期：让玩家理解脉冲与预警环，容错高迷路（落雷约 4–6 秒一发）
25 – 60%爬升期：路线决策开始有代价落雷加密（2–4 秒，50% 双发）
60 – 100%冲刺期：逼玩家在「再收一片」与「冲塔求生」间取舍三连雷、视野恶化、移速下降 6%
设计约束

任何时刻玩家都应「看得见希望」：八片碎片合计可回退约 80% 穹顶进度，理论上时间永远够用——失败应归因于掉血与迷路，而非数值绝境。

06功能需求

优先级：P0 必需 P1 重要 P2 可选　 状态：已实现 部分实现 规划中

A. 世界与天气

FR-01程序化雨夜城市P0已实现

按网格程序化生成街区、楼体与中央广场；楼体带自发光窗格，屋顶设航空警示灯；中央保留广播塔广场。

  • 验收：城市直径 ≥ 190 米，楼体 ≥ 40 栋（24 米网格叠加 16% 空地率的自然产量，均值约 45、随种子波动），无穿模；楼体为实心障碍不可攀爬。
  • 验收：每次重开布局随机，出生点固定在可通行区域。
FR-02GPU 雨幕系统P0已实现

一万四千条雨丝，位置完全在顶点着色器内计算，零 CPU 开销；雨幕随穹顶进度变厚、随风偏移。

  • 验收：雨丝 14000 条时 1080p 帧率不低于 55；雨幕在闪电瞬间整体提亮。
FR-03湿地面与积水反射P1已实现

金属度地面 + 积水潭 + 实时涟漪，闪电时被整片照亮；塔前主通道设 15 米真实镜像倒影盘（局部平面反射：512² RenderTarget、仅反射层对象入镜、相机远离自动停更、波纹扰动倒影）。

  • 策略：外围积水潭保留高光近似——全城真实反射的帧成本不可接受，属既定性能取舍。
FR-04动态环境闪电P0已实现

随机位置生成折线闪电，联动方向光、天空着色器、屏幕闪白与延迟雷声；间隔随穹顶进度从 4.2 秒缩短至 0.8 秒。

  • 验收：闪电可照亮远处楼体轮廓，具备「免费视野」的战术价值。

B. 角色与操控

FR-05第三人称角色控制P0已实现

越肩跟随相机，WASD 相对镜头移动，Shift 疾跑，空格跳跃；支持指针锁定与方向键转向双方案。

  • 验收：行走 5.0 / 疾跑 8.6；转身平滑无突兀跳变；角色碰撞半径 0.5 米。
FR-06相机避障P1已实现

相机与楼体之间做射线检测，命中时自动拉近，避免镜头穿墙。

FR-07角色演出（跑动 / 风衣 / 围巾）P1部分实现

低多边形人形 + 湿反光描边 + 摆动腿部与围巾；受击 / 拾取 / 胜负事件姿态以程序化混合实现（2026-10-28）。

  • 缺口：面部与手部细节未细化；无骨骼动画资产（维持零资产约束）。

C. 核心机制

FR-08回声脉冲P0已实现

消耗共鸣值释放声呐光纹，扩散半径 34 米，扫过时点亮楼体轮廓并使碎片显形 5 秒，同时携带扩散光源。

  • 验收：消耗 25 点，回复 7.5/秒；满值可连放 4 次。
  • 验收：玩家在纯黑环境下仅靠脉冲可完成一次完整导航。
FR-09雷纹碎片与叙事收集P0已实现

八片碎片散布全城，各对应一段弟弟的无线电残句；拾取时播放字幕与无线电音效，并回退 5% 穹顶、回复 6 点生命。

  • 验收：碎片必定生成在可通行位置（已做楼体冲突检测与重定位）。
  • 验收：八段文本构成完整叙事弧线，顺序固定。
FR-10雷暴穹顶倒计时P0已实现

300 秒倒计时，驱动落雷频率、雨幕厚度、移速衰减三条曲线，进度条常驻顶部。

  • 验收：进度走满即判定失败；拾取碎片可回退进度。
FR-11落雷预警与伤害P0已实现

地面浮现红色预警环，1.35 秒后天雷落下：中心 42 伤害、外圈 20 伤害、0.9 秒无敌、含击退与冲击波。

  • 验收：预警环清晰可辨，颜色与危险语义一致（红）。
  • 验收：落雷始终生成于玩家周围 6–22 米，高进度阶段可多连发。
  • 验收：未拾取碎片 8 米内不生成落雷（试玩公平性，2026-10-28）。
FR-12回声可交互拓展P2规划中

让脉冲具备更多战术用途：揭示落雷剩余时间、短暂打开电子门禁、标记已探索区域。

D. 界面与引导

FR-13HUD 仪表组P0已实现

生命 / 共鸣值 / 雷暴进度 / 碎片计数 / 广播塔罗盘（红）/ 最近雷纹罗盘（青），六组信息常驻；碎片罗盘补足显形 5 秒之外的持续追踪。

FR-14字幕与无线电叙事P0已实现

屏幕下方字幕承载叙事文本，配备无线电底噪与滤波音。

FR-15新手引导P1已实现

标题卡 + 字幕队列驱动的六拍分阶段引导：移动 → 首次脉冲 → 脉冲解读 → 预警环演示 → 穹顶过半提醒 → 冲塔指引；按玩家行为（移动距离、首次脉冲、首次预警）触发，即时字幕可打断并恢复队列。

FR-16结局与数据结算P1已实现

成功 / 失败双结局卡，展示碎片数、剩余生命、雨中时长三项统计。

E. 音频

FR-17程序化雷雨音频P0已实现

WebAudio 全实时合成：白噪声雨幕、低通扫频雷声、按距离延迟的雷鸣、落雷低频冲击、脉冲扫频音。

  • 验收：雷声延迟随距离变化（0–2.2 秒）；雨声音量随穹顶进度上升。
FR-18空间化音频与耳机优化P2已实现

雷声、落雷预警滴答、碎片嗡鸣走 PannerNode（HRTF，不支持时退化 equalpower），Listener 每帧跟随相机。

F. 系统与平台

FR-19性能自适应降级P1规划中

帧率低于阈值时自动下调雨丝数量、分辨率与涟漪数；提供画质档位。

FR-20设置与键位重映射P2规划中

音量、画质、灵敏度、自定义键位、暂停菜单。

FR-21移动端触控适配P2规划中

虚拟摇杆 + 脉冲按钮；需重做性能预算（雨丝数量减半）。

FR-22暂停与开局保护P1已实现

试玩反馈（2026-10-28）：点击「进入雨夜」后倒计时不再立刻开始——锁定视角即开局；指针丢失 / Esc 自动暂停并弹暂停卡；P 键随时暂停 / 继续；指针锁定不可用时按无锁模式自动开局（方向键仍可转向）。

视觉

  • 造型：低多边形（Low-poly）+ 硬边体块，弱化细节、强化剪影；楼体靠窗格自发光建立信息密度。
  • 色彩：以深蓝黑为基底，仅保留两套强调色——青（安全 / 信号 / 碎片）与红（危险 / 塔 / 落雷），其余一律降饱和。
  • 材质：高湿高反光（低粗糙度 + 高金属度），让每一次闪电都能在地面与楼体上形成可见反射。
  • 后期：雨幕斜纹、镜头水痕、暗角、闪电全屏闪白、受击红晕——全部为轻量 CSS / Canvas 叠加层，不引入后处理管线。

音频

  • 全程序化：无音频文件，雨 / 雷 / 风 / 脉冲 / 无线电全部实时合成，包体为零。
  • 雷声分层：远雷为低通扫频长尾，近雷叠加 64→24 Hz 低频冲击；延迟按距离 0–2.2 秒。
  • 叙事音：无线电残句配带通滤波底噪，强化「隔着雨与静电听人说话」的质感。
